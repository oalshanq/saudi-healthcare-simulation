# Preserved earlier GitHub prototypes

These files are snapshots of the two earlier repositories inspected on 30 October
2026. They are kept for traceability and are not used by the deployed application.

- `saudi-healthcare-simulation`: simple random-demand forecast, prior root app.
- `Capacity-Simulation-Full-`: regional DES/ABM-labelled gap calculations.

The historical filename `real_supply_data.csv` does not establish verification.
Its data are unvalidated illustrative inputs, not confirmed MOH observations.
The old map URL, Python hash-dependent specialty modifiers and simplistic model
logic are retained as historical source and should not be treated as validated.
